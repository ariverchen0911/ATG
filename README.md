可直接開啟index.html，或於此目錄執行 `python -m http.server 8816 --bind 127.0.0.1` 後開啟本機入口。附啟動POC.ps1。帳號geoinfor，密碼沿用專案指定值；僅保存加鹽PBKDF2雜湊。

建議操作順序：批次作業→案件提報→B核定→標籤快照→Q風險／能力檢核→Q候選與影子→B核准→O發布／回復。頁面角色選單為模擬，不能代表正式權限。

本版未訓練模型、未實作後端API/資料庫/持久worker，未連線正式稅籍或GIS；機率皆為null。202/503、outbox、lease、固定release與故障續作為localStorage流程模擬。公開包僅含合成案例與自訂契約，不含機關來源檔、原始schema、真實統計或來源雜湊。

新版資料使用獨立localStorage鍵；前版回饋不自動升為核定真值。舊版可由Git歷程回查。本次更新推送GitHub程式庫，不代表GitHub Pages或正式服務已部署。
